サービスの概要

Overview of Service

Beauty Content Manager（以下「本サービス」）は、美容・コスメティックスに特化したコンテンツのスケジュール管理・自動投稿ツールです。TikTok API を利用し、ユーザーが作成した動画コンテンツを指定したスケジュールに従って TikTok へ自動投稿する機能を提供します。

本サービスが提供する主な機能は以下のとおりです。

  • TikTok アカウントとの OAuth 連携認証
  • 美容・コスメ動画コンテンツのスケジュール管理と予約投稿
  • 投稿履歴・パフォーマンス分析ダッシュボード
  • ハッシュタグ・キャプション管理機能
  • 複数アカウント管理（対応プランのみ）
重要 本サービスは TikTok の公式パートナーまたは関連企業ではありません。TikTok の商標・ブランドは ByteDance Ltd. に帰属します。

TikTok アカウント連携について

TikTok Account Integration

本サービスは TikTok が提供する公式 API（TikTok API for Business / Content Posting API）を利用します。TikTok アカウントを連携することにより、以下の事項に同意いただいたものとします。

3.1 アクセス許可

  • 本サービスに対し、TikTok アカウントへのアクセス権限（コンテンツの投稿・読み取り）を付与すること
  • TikTok の OAuth 2.0 認証フローを経て、アクセストークンを本サービスが保存・使用すること
  • 投稿スケジュールに基づき、本サービスが代理で TikTok へコンテンツを投稿すること

3.2 権限の取り消し

ユーザーはいつでも TikTok のアカウント設定から本サービスへのアクセス権を取り消すことができます。権限の取り消し後は、スケジュール済みの投稿も含め、すべての自動投稿機能が停止されます。

3.3 TikTok 規約の遵守

本サービスを通じた TikTok へのコンテンツ投稿は、TikTok の以下の規約に従う必要があります。

  • TikTok 利用規約（Terms of Service）
  • TikTok コミュニティガイドライン（Community Guidelines）
  • TikTok クリエイターマーケットプレイスポリシー（該当する場合）
  • TikTok 広告ポリシー（有料プロモーション含む場合）
TikTok の API 仕様変更、サービス中断、ポリシー改定により、本サービスの一部または全部の機能が影響を受ける場合があります。これらは当社の管理外であり、責任を負いかねます。
